# 2026-11-08 — renderer, sound, save states, front end (0.2.0)

All checks below were run in the build container (Ubuntu 24.04, gcc 13, SDL 2.30) and, for
Windows, with MinGW-w64 executables under Wine 9 with Xvfb. No physical Windows PC, Steam
Deck or controller was available.

| Check | Command / method | Result |
| --- | --- | --- |
| Attract mode vs MAME 0.264 | `nsl_headless --frames 3600 --png-every 120`, MAME snapshots every 120 frames | frames match visually (tiles, sprites, alpha, fades); 1-2 frame timing offset |
| Gameplay | `--coin-at 200 --start-at 300 --autoplay N`, 20,000 frames ×3 seeds | game starts, scores, dies, continues; no faults |
| Translator vs fallback | same 3,600 frames with and without seeds | identical RAM/frame/palette hashes |
| Audio vs MAME | `--wav`, MAME `-wavwrite`, 62 s | envelope correlation 0.92, RMS ratio 1.007, spectral bands within 1.5 % |
| Save state round trip, attract | save at 2000, resume 600 frames | 600/600 frames identical (audio, RAM, video, palette) |
| Save state round trip, gameplay | autoplay to 2000, save, resume 600 frames | 600/600 identical |
| Damaged / truncated / foreign states | byte flips in payload and header, 100-byte file | rejected: checksum, header, too short |
| Windows build | `nsl_headless.exe` under Wine, 3,600 frames | hashes identical to Linux |
| Front end (Linux, Windows/Wine) | `tests/ui_smoke.sh` scripted session | menus, settings, slot save with preview/timestamp, F5/F8, autosave, Continue, return to menu |
| ROM picker | bad zip, good zip, folder with spaces + `Ñ` + Japanese | bad zip lists missing files; good zip loads; path remembered |
| Layouts | 1280x800 (Steam Deck), 1920x1080, 960x720 | readable, no clipping |
| AppImage | run with `--appimage-extract-and-run` on Xvfb, ROM next to the AppImage | finds ROM, runs scripted session |
